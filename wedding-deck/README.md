## クイズの進め方

**答えが先に見えてしまわないよう、問題と答えはスライドを分けています。**

1. **問題スライド** — 問題と、左右2つの答えを読み上げる
2. **クリック** → 10秒カウントダウン（右上の丸が 10→0）＋カウントダウンBGM。
   このあいだに、正しいと思う側へ会場を移動してもらいます
3. **クリック** → こたえスライドへ。表示した瞬間に効果音が鳴り、矢印と正解が出ます
4. **クリック** → 次の問題へ

左の答えだと思う人は画面に向かって左へ、右の答えだと思う人は右へ。

**こたえスライドには正解しか載せていません。** 裏の取れていない補足コメントは一切入れていないので、
エピソードを足したいときは画面はそのままで口頭でどうぞ。各スライドのノート欄に正解と進行手順があります。

## 正解の左右

常に同じ側が正解にならないよう散らしてあります。

```
右 左 左 右 左 右 右 左 右 左 右 左 右   （左6問 / 右7問・同じ側の連続は最大2問）
```

`verify_deck.py` が、片側固定・3問以上の連続・左右の偏り、こたえスライドの余計な文言、
そして穴埋め表記（`{{ }}` や 〇〇）の残りを自動で弾きます。

左右を入れ替えたいときは `content.py` の `side` を `"left"` / `"right"` で書き換えるだけです
（左右の文言も写真も一緒に入れ替わります）。
正解そのものを変えたいときは `correct` と `dummy` を入れ替えてください。

## 音が鳴るところ

効果音はすべて「押していくと勝手に流れる」ようにしてあります。再生ボタンを押す操作はありません。

| 場所 | 音 | 鳴り方 |
|---|---|---|
| 問題スライド | 10秒カウントダウンBGM | クリック1回目 |
| こたえスライド | 正解発表の効果音 | スライドを表示した瞬間に自動 |
| 乾杯・セクション扉・ビンゴ | ファンファーレ／ドラムロール | スライドを表示した瞬間に自動 |
| 36枚目 中村になろうよ | BGM | スライドを表示した瞬間に自動 |

## 仮で入れてある値

スライドに `{{ }}` のような穴埋め表記は残していません。
答えが分からなかった箇所はそれらしい値を入れてあるので、そのままでも通して使えます。

| 場所 | 仮の値 |
|---|---|
| 第1問 ダミーの司会者名 | 森下 詩織 さん（ご列席者と被る場合は差し替えを） |
| 第2問 台風の号数 | 正解 18号／ダミー 17号 |
| 第3問 正解 | 「1週間以内」（違う場合は `correct` と `dummy` を入れ替え） |

結果発表は表彰をせず、その場で拍手して次へ進む形です。優勝者名や景品名を入れる欄はありません。

## 「中村になろうよ」のBGM差し替え ⚠️

いまは**無音のダミー音源**が入っています。**本番までに必ず差し替えが必要です。**

動画を添付いただいたとのことでしたが、こちらには届いていませんでした。
mp3（または音声を含む動画ファイル）をお送りいただければ、音声だけ取り出して組み込みます。
ご自身で差し替える場合の手順は、36枚目のノート欄に書いてあります。

## ビルドし直す

```bash
pip install python-pptx Pillow lxml
python3 make_assets.py    # 背景画像・写真のトリミング・ダミー音源を生成
python3 build_deck.py     # pptx を書き出し
python3 verify_deck.py    # 参照・アニメーション・問題と答えの分離・左右の散らしを検査
```

文言だけ直したいときは `content.py` を編集して `build_deck.py` を再実行してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `content.py` | 問題・進行・ルール・ビンゴの原稿。文言と正解の左右はここだけ直せば済む |
| `build_deck.py` | スライドの組み立て（レイアウト・配色） |
| `pptx_motion.py` | python-pptx が扱えないアニメーションと効果音を素の OOXML で生成 |
| `make_assets.py` | 背景画像・写真のトリミング・ダミー音源の生成 |
| `verify_deck.py` | 書き出した pptx の自動検査 |
| `assets/sfx/` | 効果音（元スライドから流用） |
| `assets/img/` | 背景画像・スピーカーアイコン・写真問題の素材（`q_*.jpg`） |
| `assets/photos_src/` | 写真の元データ。`make_assets.py` が同じ縦横比に切り出す |
