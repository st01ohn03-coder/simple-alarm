# 結婚式 ○×クイズ＆ビンゴ スライド

`build/結婚式_マルバツクイズ＆ビンゴ.pptx`（全29枚）を生成するためのソース一式。

構成と演出のテンション感は、お預かりした **『チーム対抗企画スライド 3』** を下敷きにしています。
効果音（10秒カウントダウンBGM／正解発表音／ドラムロール）も同スライドから引き継いで再利用しました。

| 2–4 | ルール説明（○×クイズとは／移動のしかた／お願い） |

| 29 | エンディング |

## 問題スライドの動かし方（クリック2回）

1. **問題を読み上げる** — 問題文と ○ / × は最初から出ています
2. **1クリック目** → 10秒カウントダウン（右上の丸が 10→0）＋カウントダウンBGM。この間に会場を移動してもらいます
3. **2クリック目** → 正解側に赤枠が出て点滅＋正解発表の効果音、下に解説が出ます

○ ＝ 画面に向かって**左**、× ＝ 画面に向かって**右**。全スライド共通です。

各スライドのノート欄に、正解・進行手順・元ネタを書いてあります。

## 音が鳴るところ

| 場所 | 音 | 鳴り方 |
|---|---|---|
| 問題スライド | 10秒カウントダウンBGM | 1クリック目 |
| 問題スライド | 正解発表の効果音 | 2クリック目 |
| セクション扉・ビンゴ各スライド | ドラムロール／ファンファーレ | スライドを表示した瞬間に自動 |
| 28枚目 | 家族になろうよ | 「BGM再生ボタン」をクリックしたときだけ |

28枚目だけは PowerPoint の**トリガー**を使っているので、スライドを送る普通のクリックでは鳴りません。

## 「家族になろうよ」の差し替え

いまは**無音のダミー音源**が入っています。mp3 をいただければこちらで組み込みます。
ご自身でやる場合の手順は28枚目のノート欄に書いてあります。

## ビルドし直す

```bash
pip install python-pptx Pillow lxml
python3 make_assets.py    # 背景画像とダミー音源を生成
python3 build_deck.py     # pptx を書き出し
python3 verify_deck.py    # 参照・アニメーション・正解位置を検査
```

文言だけ直したいときは `content.py` を編集して `build_deck.py` を再実行してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `content.py` | 問題・ルール・ビンゴの原稿。文言はここだけ直せば済む |
| `build_deck.py` | スライドの組み立て（レイアウト・配色） |
| `pptx_motion.py` | python-pptx が扱えないアニメーションと効果音を素の OOXML で生成 |
| `make_assets.py` | 背景画像とダミー音源の生成 |
| `verify_deck.py` | 書き出した pptx の自動検査 |
| `assets/sfx/` | 効果音（元スライドから流用） |
| `assets/img/` | 背景画像・スピーカーアイコン・幼少期の写真 |
