# 結婚式 2択クイズ＆ビンゴ スライド

`build/結婚式_2択クイズ＆ビンゴ.pptx`（全40枚）を生成するためのソース一式。

構成と演出のテンション感は、お預かりした **『チーム対抗企画スライド 3』** を下敷きにしています。
効果音（10秒カウントダウンBGM／正解発表音／ドラムロール）も同スライドから引き継いで再利用しました。

## スライド構成

流れは **① 2択クイズ大会 → ② 中村になろうよ → ③ ビンゴ大会**。

| # | 内容 |
|---|---|
| 1 | 表紙 |
| 2–4 | ルール説明（2択クイズとは／移動のしかた／お願い） |
| 5 | セクション扉「2択クイズ」 |
| 6–31 | 2択クイズ 全13問 × 2枚（問題→こたえ） |
| 32 | セクション扉「結果発表」 |
| 33 | 優勝発表 |
| 34 | 中村になろうよ（BGM自動再生） |
| 35 | セクション扉「ビンゴ大会」 |
| 36–39 | ビンゴ進行（ルール／スタート／リーチ／ビンゴ） |
| 40 | エンディング |

景品発表のスライドはご指示どおり入れていません。

## クイズの進め方

**答えが先に見えてしまわないよう、問題と答えはスライドを分けています。**

### 問題スライド（クリック1回）
1. 問題と、左右2つの答えを読み上げる
2. **クリック** → 10秒カウントダウン（右上の丸が 10→0）＋カウントダウンBGM。
   このあいだに、正しいと思う側へ会場を移動してもらいます
3. **クリック** → こたえのスライドへ

### こたえスライド（自動＋クリック1回）
4. スライドが出た瞬間に効果音が鳴り、矢印と正解が出ます（クリック不要）
5. **クリック** → 下の解説コメントが出ます

左の答えだと思う人は画面に向かって左へ、右の答えだと思う人は右へ。
各スライドのノート欄に、正解・進行手順・補足を書いてあります。

## 正解の左右

常に同じ側が正解にならないよう散らしてあります。

```
右 左 左 右 左 右 右 左 右 左 右 左 右   （左6問 / 右7問・同じ側の連続は最大2問）
```

`verify_deck.py` が、片側固定・3問以上の連続・左右の偏りを自動で弾きます。

左右を入れ替えたいときは `content.py` の `side` を `"left"` / `"right"` で書き換えるだけです
（左右の文言も写真も一緒に入れ替わります）。
正解そのものを変えたいときは `correct` と `dummy` を入れ替えてください。

## ビルドし直す

```bash
pip install python-pptx Pillow lxml
python3 make_assets.py    # 背景画像・写真のトリミング・ダミー音源を生成
python3 build_deck.py     # pptx を書き出し
python3 verify_deck.py    # 参照・アニメーション・問題と答えの分離・左右の散らしを検査
```

文言だけ直したいときは `content.py` を編集して `build_deck.py` を再実行してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `content.py` | 問題・ルール・ビンゴの原稿。文言と正解の左右はここだけ直せば済む |
| `build_deck.py` | スライドの組み立て（レイアウト・配色） |
| `pptx_motion.py` | python-pptx が扱えないアニメーションと効果音を素の OOXML で生成 |
| `make_assets.py` | 背景画像・写真のトリミング・ダミー音源の生成 |
| `verify_deck.py` | 書き出した pptx の自動検査 |
| `assets/sfx/` | 効果音（元スライドから流用） |
| `assets/img/` | 背景画像・スピーカーアイコン・写真問題の4枚（`q_*.jpg`） |
| `assets/photos_src/` | 写真問題の元データ。`make_assets.py` が同じ縦横比に切り出す |

## 注意点

- フォントは **Meiryo** 指定です。Mac で開く場合は別のフォントに置き換わります
- ご指示どおり、腕立て伏せの企画と景品発表は入れていません
- 写真問題は「本物 vs AI生成」。正解＝本物（口が開いている幼少期／カルピス）、
  ダミー＝AI生成（口が閉じている幼少期／ワイン）
