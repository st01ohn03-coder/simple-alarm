# 絵コンテ・台本

尺 **39.4秒** / 30fps / 全1182フレーム
日本語ナレーション付き（-16 LUFS）。ただし**ミュート自動再生でも成立する**ように、
伝えたいことはすべて画面文字に出してある。ナレーションは補助。

タイムコードは `src/timeline.js` の `SCENES` 配列と一対一で対応している。

| 変えたいもの | 触るファイル |
|---|---|
| 文言・構成要素 | `src/video.html` |
| 出るタイミング・シーンの長さ | `src/timeline.js` |
| ナレーション原稿・声・速度 | `tools/narration.py` |

シーンの長さは `src/timeline.js` が唯一の正で、`tools/narration.py` はそこから
区間を読み出す。尺を変えたらナレーションを作り直せば自動で追従する。

## ナレーション

音声合成は edge-tts（Microsoft Edge のニューラル音声）。
既定は `ja-JP-NanamiNeural`（女性）、速度 `+6%`。
各セリフはシーン開始の 0.45 秒後から読み始める。

| 読み始め(秒) | シーン | 原稿 |
|---:|---|---|
| 0.45 | S1 | その ピーディーエフ、開くだけで終わっていませんか。 |
| 4.75 | S2 | いきなり ピーディーエフ バージョン 13、コンプリート。 |
| 8.85 | S3 | 作成、ページ編集、変換、注釈。これ一本で。 |
| 14.75 | S4 | ワープロ感覚で、ピーディーエフ を直接編集。 |
| 19.15 | S5 | 墨消しも、電子署名も。見せない、変えさせない。 |
| 24.35 | S6 | 新機能、紙の ピーディーエフ 化。エーアイ が分割して、名前まで付けます。 |
| 31.15 | S7 | サブスクは毎年払う。コンプリートは、一回だけ。 |
| 36.45 | S8 | いきなり ピーディーエフ、コンプリート。 |

原稿は `tools/narration.py` の `LINES` にある。
TTS が読み違える語はカタカナで書いてある（PDF→ピーディーエフ、AI→エーアイ）。

書き換えたら必ず尺を確認する。

```bash
python3 tools/narration.py --check
```

各セリフを実測して、シーン終端の 0.30 秒前までに読み終わるかを表に出す。
はみ出す場合は、原稿を短くするか `--rate +10%` で速度を上げるか、
`src/timeline.js` でそのシーンを長くする。

### 音づくりの方針

- セリフごとにラウドネスを実測して -19 LUFS に揃えている。
  動的な正規化は使わない（区間ごとに音量が揺れるため）。実測でセリフ間の差は 1.1 dB。
- 全体は -16 LUFS、トゥルーピーク -5 dBFS。
- 環境音は権利処理の要らない自前合成のパッド。ナレーションの約 20 dB 下に敷いてある。
  `--no-music` で外せる。
