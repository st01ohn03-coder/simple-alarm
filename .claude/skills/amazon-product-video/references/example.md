# 実例：PDF編集ソフトの商品動画

何をどう判断して、どういう構成にしたか。
**構成をそのまま真似るのではなく、判断の仕方を読んでほしい。**

対象は Windows 用の PDF 編集ソフト。上位版と下位版があり、評価は ★3.3（82件）だった。

---

## 商品ページから読み取ったこと

### A+（商品紹介）が言っていたこと

- 選ばれる理由として「買い切りのコスパ」と「オールインワン」を挙げていた
- 部門別の利用シーン（経営企画・業務経理・法務人事）を並べていた
- 実績として「15年連続 販売本数第1位」「シェア52%」「累計360万本」「導入15,000社」
- **上位版と下位版の比較表があった**

### 比較表から取れた差

上位版だけができることは4つだけだった。

| 機能 | 上位版 | 下位版 |
|---|:--:|:--:|
| 作成・ページ編集・変換・注釈 | ○ | ○ |
| **既存テキストの直接編集** | ○ | × |
| **紙のPDF化（AIが自動命名・分割）** | ○ | × |
| **電子署名** | ○ | × |
| **墨消し** | ○ | × |

**ここが訴求の芯になる。** 上位版を買う理由は、この4つしかない。

### レビューの分布

★3.3 で、星5が36%・星1が21%。**両端に割れている。**

本文は取れなかったが、この分布は「機能は良いが、期待した機能が入っていなかった」型の
不満が一定数あることを示している。下位版と上位版があり、機能差が比較表の奥にある商品では
よく起きる。

---

## 潰すと決めた購買障壁

指名検索で来る人が多い商品なので、認知ではなく**買う直前の引っかかり**を外すことにした。

| 障壁 | そう考えた根拠 | 打ち手 | シーン |
|---|---|---|---|
| 自分の用途に足りるか分からない | 機能が多く、何ができるか伝わりにくい | 実画面で基本機能4つを並べる | S3 |
| 上位版を買う理由が分からない | 差が比較表の奥にある | 「この版だけの機能」を金色リボンで2回明示 | S4・S5 |
| 買い切りは損しないか | A+ が買い切りを推している | 支払い回数を棒グラフで可視化 | S7 |
| 買ってから違ったと思いたくない | ★3.3 で星1が21% | 対応環境・台数・提供形態を最後に出す | S8 |

---

## 組み立てた構成（全39.4秒）

```
0:00.0  S1 フック      「開くだけの○○、もう卒業。」＋ できない悩み4つ
0:04.3  S2 製品提示    パッケージ＋製品名＋機能タグ6種
0:08.4  S3 基本機能    4つの用途を実画面で（作成／ページ編集／変換／注釈）
0:14.3  S4 上位版①    いちばんの差を実画面で（直接編集）
0:18.7  S5 上位版②    不安を潰す4要素（墨消し・署名・時刻・パスワード）
0:23.9  S6 新しさ      最新版の新機能（AI による自動整理）
0:30.7  S7 コスト      毎年払う方式 vs 1回だけ
0:36.0  S8 クロージング 実績3つ＋対応環境
```

### 効いた設計

**冒頭の悩み4つを、後半で全部回収した。**
S1 で出した「文字を直したい／一部を墨消ししたい／電子署名を押したい」は、
すべて上位版だけの機能。フックと上位版訴求が同じ線でつながる。

**実画面を使った。** 抽象的なアイコンだけより「本当にできる」と伝わる。
素材は商品ページ掲載画像から切り出した。

**新機能を中盤に置いた。** 旧バージョンからの買い替え層に効く差分。
生成AI 文脈（透明テキストOCR）は購買動機として強い。

**コスト比較は最後から2番目。** 機能で納得させた直後に価格不安を潰すのが、
意思決定の順番として自然。

**最後に仕様を隠さず出した。** 対応OS・台数・ライセンス形態。
CVR だけでなく返品とレビューにも効くはず、という判断。

---

## 価格を入れなかった理由

A+ には「5年で105,820円お得」という強い訴求があった。
これは効くが、**そのまま動画に入れるとガイドライン違反になる。**

そこで「支払い回数」の比較に置き換えた。
毎年払う方式の棒を5本積み上げ、買い切りの棒を1本だけ置く。
金額は一切出していないが、構造の差は一目で伝わる。

```
毎年払う方式          この商品
  5年目 ■              最初の1回だけ ■
  4年目 ■
  3年目 ■       VS
  2年目 ■
  1年目 ■
```

こういう置き換えは、たいていの「価格が強みの商品」で使える。

## 検品で見つかった欠陥

目視では通っていたが、可読性の検品で4件落ちた。全部直した。

| 箇所 | 実測 | 原因 |
|---|---|---|
| 橙のタグ | 2.2:1 | 白文字を橙に乗せていた |
| バージョン表記 | 2.1:1 | 明るい青の上に水色 |
| 棒グラフのラベル | 3.1:1 | 白文字をグレーに |
| 1:1 版の本文 | 高さの1.3% | 文字サイズを幅だけで決めていた |

**目視は当てにならない。** 作った本人は見慣れてしまうので、機械に見せる。

## ナレーション

8本。各シーンの頭 0.45 秒後から読み始める。

| シーン | 原稿 |
|---|---|
| S1 | その○○、開くだけで終わっていませんか。 |
| S2 | （商品名）、（エディション名）。 |
| S3 | 作成、ページ編集、変換、注釈。これ一本で。 |
| S4 | ワープロ感覚で、○○を直接編集。 |
| S5 | 墨消しも、電子署名も。見せない、変えさせない。 |
| S6 | 新機能、（機能名）。エーアイ が分割して、名前まで付けます。 |
| S7 | サブスクは毎年払う。これは、一回だけ。 |
| S8 | （商品名）、（エディション名）。 |

短い。**画面文字と同じことを言わない**が、離れすぎない。
ミュートでも成立させる前提なので、ナレーションは補助。

S5 の「見せない、変えさせない。」のような対句は、耳にも画面にも残るので効く。

---

## 次に試すとよいこと

1. **フック違い**：問題提起型 vs ベネフィット直球型
2. **尺違い**：15秒版（S1→S2→S4→S7→S8）。広告用は15秒前後が回りやすい
3. **上位版訴求の位置**：S2 直後に前倒しして、下位版と迷う人の離脱を早く止める
4. **声違い**：女性 vs 男性。BtoB 寄りの商材なら男性が効く可能性がある
5. **レビューの変化**：仕様明示によって「思っていたものと違った」系が減るかを前後比較
