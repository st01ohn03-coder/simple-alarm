# Simple Alarm

すごくシンプルな UI のアラーム Web アプリ。**HTML 1 ファイルだけ**で動きます。ビルド不要、依存ゼロ。

外出先から自宅PCのアラームをセットしたり、自宅PCに登録しておいた作業を実行させる **リモートモード** も付いています（こちらも依存ゼロ・Node.js 標準モジュールのみ）。

![preview](https://img.shields.io/badge/single--file-HTML-7cc4ff?style=flat-square)

## 特徴

- 単一の `index.html` のみでローカル動作。ダブルクリックで起動。
- 大きなデジタル時計（秒まで表示）
- アラーム時刻を 1 つセットできる
- 発火時：画面が赤く点滅 + Web Audio API で生成したビープ音
- 「停止」ボタンを押すまで鳴り続ける
- ダークテーマ、レスポンシブ
- **リモートモード**：外出先のスマホから自宅PCのアラームを操作／自宅PCで作業を実行

## 使い方（ローカルモード）

1. `index.html` をブラウザで開く（ダブルクリックでも OK）
2. アラーム時刻を入力
3. **セット** を押す
4. 設定時刻になると鳴るので **停止** を押す

途中で止めたいときは **解除** を押してください。

> ブラウザのオートプレイ制限により、初回は **セット** を 1 度押す（＝ユーザー操作を経る）まで音が鳴らない場合があります。

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## リモートモード（自宅PCと連動）

外出先のスマホから自宅PCを操作します。

```
  スマホのブラウザ            中継サーバー              自宅PC
  (index.html)      ──▶   (relay/server.js)   ──▶   (agent/agent.js)
   セット / 停止              どこかの VPS 等            アラームを鳴らす
   作業ボタン                                          登録した作業を実行
```

- 自宅PCから中継サーバーへ **外向きに** 接続するので、自宅ルーターのポート開放は不要です。
- 中継サーバーは仲介するだけで、コマンドの内容を解釈しません。
- リモートから送れるのは **タスクの id だけ**。実行するコマンドは自宅PC側の `agent/tasks.json` でしか決められません。

### 1. 中継サーバーを立てる

インターネットから届く場所（VPS や PaaS）で動かします。**必ず HTTPS 経由で公開してください。**

```bash
# トークンを生成
node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"

# 起動
ALARM_TOKEN=<生成したトークン> node relay/server.js
```

`PORT`（既定 8787）で待ち受けます。中継サーバーは `index.html` も配信するので、スマホからは
`https://<中継サーバー>/` を開くだけで使えます。

### 2. 自宅PCでエージェントを動かす

```bash
RELAY_URL=https://<中継サーバー> ALARM_TOKEN=<同じトークン> node agent/agent.js
```

アラーム発火時は、自宅PCで OS の音（`afplay` / `powershell` の beep / `paplay` など）とデスクトップ通知が出ます。

### 3. スマホから操作する

1. `https://<中継サーバー>/` を開く
2. **リモート** タブ →**設定** に中継サーバーの URL とトークンを入力 → **接続**
3. リレーと自宅PCのランプが両方緑になれば準備完了

セット／解除／停止と、登録した作業のボタンが使えます。時刻や実行結果は開いている全端末に即時同期されます。

### 自宅PCにやらせる作業を登録する

`agent/tasks.example.json` をコピーして `agent/tasks.json` を作ります。

```json
{
  "tasks": [
    {
      "id": "music",
      "label": "音楽を再生",
      "platform": "win32",
      "command": "C:\\Users\\me\\bin\\play-music.bat",
      "args": []
    }
  ]
}
```

| キー | 説明 |
| --- | --- |
| `id` | リモートから指定する識別子（必須） |
| `label` | ボタンに出す名前（省略時は `id`） |
| `command` | 実行するコマンド（必須） |
| `args` | 引数の配列（文字列のみ） |
| `platform` | `win32` / `darwin` / `linux`。省略で全OS。OSごとに同じ `id` で書き分け可 |
| `timeoutMs` | タイムアウト（既定 60000、最大 600000） |

コマンドは **シェルを介さず** 実行されます。`&&` やパイプ、リダイレクトは使えないので、複数の処理をまとめたいときはシェルスクリプトやバッチファイルを 1 つ作り、それを `command` に指定してください。

例（`tasks.example.json` に同梱）：画面をロック / スリープ / 音量を上げる / ミュート解除 / ニュースを開く / PCの状態を見る

`tasks.json` を書き換えたら、アプリの **再読み込み** を押せばエージェントを再起動せずに反映されます。

### セキュリティ

自宅PCでコマンドを実行できる仕組みなので、次の点を守ってください。

- **中継サーバーは必ず HTTPS で公開する。** トークンが平文で流れます。
- **トークンは十分に長いものを使う**（16 文字未満だと起動を拒否します）。総当たりに対しては、認証失敗が 1 分間に 10 回を超えた IP を一時的に弾きます。
- **`agent/tasks.json` に危険なコマンドを書かない。** 実行できるのはここに書いたものだけなので、このファイルが実質的な権限の境界です（`.gitignore` 済み）。
- エージェントは実行したユーザーの権限で動きます。管理者権限で常駐させないでください。
- トークンが漏れたら、中継サーバーとエージェントの `ALARM_TOKEN` を変えて再起動してください。

### うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| 「自宅PC オフライン」のまま | エージェントのログを見る。401 ならトークン不一致 |
| 「リレー未接続」のまま | URL が合っているか、HTTPS か、中継サーバーが起動しているか |
| PCで音が鳴らない | 下の `alarm.test` で鳴らしてみる。エージェントのログに「音を鳴らすコマンドが見つかりません」が出ていないか（Linux は `pulseaudio-utils` / `alsa-utils` が必要） |
| 作業ボタンが空 | `agent/tasks.json` の `platform` が現在のOSと一致しているか |
| 通知が出ない | Linux は `notify-send`（`libnotify-bin`）が必要 |

時刻を待たずに鳴らして確かめたいときは、`alarm.test` を送ります（停止は `alarm.stop`）。

```bash
curl -X POST https://<中継サーバー>/api/command \
  -H "Authorization: Bearer $ALARM_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type":"alarm.test"}'
```

## 動作環境

- ローカルモード：最近のモダンブラウザ（Chrome / Edge / Firefox / Safari）。Web Audio API 必須。
- リモートモード：上記に加えて Node.js 18 以上（中継サーバーと自宅PC）。
