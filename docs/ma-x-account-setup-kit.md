# X / Instagram アカウント作成キット(15分で開設できる状態)

Google・X・Instagram のアカウント開設は SMS認証とCAPTCHA が必須のため本人の端末での操作が必要。
その代わり、入力する内容をすべてここに用意した。スマホ片手にこの通り進めれば15分で完了する。

---

## STEP 1: Googleアカウント作成(5分)

https://accounts.google.com/signup

| 項目 | 入力値(案) |
|---|---|
| 姓名 | 運用名でOK(例: 姓「M&A」名「情報局」※後で変更可) |
| Gmailアドレス候補 | `ma.johokyoku@gmail.com`(第1候補)/ `ma.johokyoku.jp@gmail.com` / `ma.joho.jp@gmail.com` |
| パスワード | パスワードマネージャーで生成(使い回し禁止) |
| 電話番号 | 本人のスマホ(SMS認証用・必須) |
| 再設定用メール | 普段使いのメール(st01.ohn03@gmail.com) |

作成後にやること:
- [ ] 2段階認証を有効化(設定 > セキュリティ)

## STEP 3: Instagramアカウント作成(3分・当面はユーザー名確保のみ)

https://www.instagram.com/ → STEP 1のGmailで登録

- ユーザー名: **Xのハンドルと同じものを取る**(ブランド統一のため。例: `ma_anken_memo`)
- プロフィール文: Xの案Aを短縮して使用
- 当面は投稿せず**ユーザー名の確保だけ**。将来、Xで伸びた投稿を画像化(案件カード)してリール/フィードに展開する
- 非公開にはせず、固定投稿1枚(アカウント紹介の画像)だけ置いておくと自然
