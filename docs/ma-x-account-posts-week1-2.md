今日の用語解説📻

【DD(デューデリジェンス)】
買収前に行う調査のこと。財務・法務・事業の中身を精査する。

スモールM&Aでも最低限、
・直近3年の決算書
・借入と担保
・簿外債務の有無
は必ず確認。ここをサボると高確率で後悔します。

## Day 8〜13(平日ローテーション)

朝は下記ストックから1本、夜は[穴埋め]案件紹介を継続。

### 朝ストックA [完成]
```
売り手側の話も。

会社を売ると決めてから成約までの期間は、スモールM&Aでも平均して半年〜1年。

「まだ先の話」と思っている社長ほど、情報収集だけでも早く始めた方がいい理由がこれです。

売り時は、業績がいい時。
```

### 朝ストックB [完成]
```
M&Aの価格って誰がどう決めてるの?という話。

スモールM&Aでよく使われる目安は
「時価純資産 + 営業利益2〜5年分」

同じ利益でも、属人性が低い(社長がいなくても回る)ほど高く売れます。
```

### 朝ストックC [完成]
```
個人M&Aで人気の業種ランキング(当局調べの肌感覚):

①飲食店(参入イメージが湧きやすい)
②EC・ネットショップ(在宅で回せる)
③学習塾・スクール(ストック収入)
④美容室(店舗+顧客リスト)
⑤ブログ・メディア(数十万円から)

あなたならどれを買いますか?
```

### 朝ストックD [完成]
```
「廃業」と「売却」の差は、想像以上に大きい。

廃業: 設備は二束三文、従業員は解雇、取引先に迷惑
売却: 事業は続き、雇用も残り、社長には対価が入る

それでも日本では、売却を検討すらせず廃業する会社が多数派。
知られていないだけ、なんですよね。
```

### 朝ストックE [完成]
```
Xアカウントって売買できるの?という質問に答えます。

アカウント単体の売買は規約違反リスクがあります⚠️
実務では「事業譲渡の一部としてSNSアカウントも承継する」形が取られます。

“アカウントを買う”のではなく“アカウント込みの事業を買う”。ここ重要です。
```

### 朝ストックF [完成]
```
公的な無料相談窓口、意外と知られていません。

「事業承継・引継ぎ支援センター」
→ 全47都道府県にあり、国が設置。売り手も買い手も無料相談可。

いきなり仲介会社に行く前に、ここで相場観をつかむのも手です。
```
