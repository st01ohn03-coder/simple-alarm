# M&A情報局 SNS全体戦略(X × Instagram × Threads)

ゴール: **「会社を買いたい人」を集客する**メディアを作る。
フォローする理由 = 「ここを見てれば良い案件と出会える」「買い方が学べる」。

---

## 1. 全体設計(ファネル)

```
X(毎日)        = 発見される場所。数字フックで新規リーチを取る
Instagram(毎日) = 信頼を貯める場所。同じ案件を「保存したくなる資料」に変換
Threads(流用)   = Xと同文を転載するだけ(コスト0で面を増やす)
     ↓
プロフィール → 将来: LINE公式/問い合わせ → 案件相談(マネタイズ)
```

- Xは「フロー(流れて消える)」、Instagramは「ストック(保存されて効く)」
- 同じ案件ネタを**1ソース2フォーマット**で使い回す。制作は1回、露出は2倍
- Instagramのアルゴリズムは**保存率**が最重要。「あとで見返したい案件シート」は保存されやすい=構造的に有利

## 2. Instagram フィード7枚構成(カルーセル骨組み)

### 型A: 案件詳細シート型(メイン・週4〜5回)

| 枚数 | 役割 | 内容 |
|---|---|---|
| 1枚目 | 表紙(フック) | 数字ギャップを大きく。「売上1億の工場が1,100万円」+「▶スワイプで詳細」 |
| 2枚目 | 案件概要 | 業種/地域/従業員/業歴 をアイコン付きで一覧 |
| 3枚目 | お金の数字 | 売上・営業利益・希望価格 を棒グラフ的に見せる(ここが本体) |
| 4枚目 | 回収シミュレーション | 「価格÷利益=◯年で回収」を図解。前提条件も明記 |
| 5枚目 | この案件の考察 | 考察7型(回収/属人性/隠れ資産…)から1つ。箇条書き3点まで |
| 6枚目 | 注意点(DDポイント) | 「買う前に確認すべき3つ」— 誠実さが信頼になる |
| 7枚目 | CTA | 「出典はプロフィール/ハイライトから」「保存して案件と比較」「フォローで毎日届く」 |

### 型B: 学び・図解型(週1〜2回・変化球)

1. 表紙:「会社の値段はどう決まる?」等の疑問形
2〜6. 図解で1テーマ解説(相場表/用語/失敗例/資金調達)
7. CTA

### 運用ルール
- 表紙の言葉はXのフック2行をそのまま流用(検証済みのフックを使い回す)
- キャプション: Xの本文をほぼコピペ+ハッシュタグ(#M&A #事業承継 #スモールM&A #会社を買う #脱サラ #副業 など10個前後。IGはXと違いタグが有効)
- 出典リンクはキャプションに書いてもタップ不可のため、**プロフィールのリンク集(lit.link等)+ストーリーズのリンクスタンプ**で対応

## 3. デザイン・トンマナ(色調)

| 要素 | 指定 |
|---|---|
| 基調色 | 濃紺 #0B1F3A(金融・信頼) |
| 背景 | オフホワイト #F7F5F0 |
| アクセント | 金 #C9A227(価格などキー数字のみ)+ 案件カテゴリ色(飲食=赤茶/製造=鉄紺/IT=青緑/店舗サービス=橙 など帯色で区別) |
| フォント | 見出し: Noto Sans JP Black / 本文: Noto Sans JP Regular。数字は極端に大きく(画面の1/3) |
| レイアウト | 1080×1350(4:5)。上部に「M&A情報局|案件シート」の定型ヘッダー帯、下部にページ番号。毎回同じ骨格=フィードが「資料集」に見える |
| 写真 | 使わない(フリー素材感が出て信頼が下がる)。図形+数字+文字だけのインフォグラフィックで統一 |

## 4. 制作ワークフロー(1案件 → X+IG)

```
① 案件巡回(既存フロー) → その日のベスト案件を選定
② X原稿作成(v2フォーマット)
③ 同じ内容を7枚構成に分解(表紙=フック/3枚目=数字/5枚目=考察)
④ 画像7枚を生成 → ユーザーに納品
⑤ ユーザー: Xに投稿(朝) → Instagramに投稿(夜) → Threadsにコピペ
```

### 画像生成の実装(このセッションでできる)
ChatGPT等の外部ツールは不要。**HTMLテンプレート(上記トンマナを埋め込み)を作り、案件データを流し込んで、ヘッドレスブラウザで1080×1350のPNG7枚を書き出す**方式。
- 毎回同じデザインで量産できる(生成AI画像より一貫性が高い)
- テンプレは一度作れば文言差し替えだけ
- 「今日の案件をIG用にして」と言えば7枚のPNGを納品

## 5. Xの投稿バリエーション体系(拡張版)

| 型 | 頻度 | 内容 |
|---|---|---|
| 案件ピックアップ(既存v2) | 毎日1〜2本 | 数字フック+考察 |
| 決算・IR翻訳型 | 週2〜3本 | 上場企業の適時開示・決算を「翻訳」。「時価総額42億の会社が32億の買収→何を買ったのか」(本家の勝ち型) |
| IPO解説型 | 随時 | 新規上場企業の目論見書から「この会社は何で稼いでいるか」を平易に解説 |
| 画像付き投稿 | たまに | 決算短信・IR資料の該当ページのキャプチャを添付して解説。※出典明記の引用の範囲で(出所・ページを記載、必要部分のみ) |
| 学び・相場型 | 週2本 | 既存ストック(用語・相場・失敗例) |
| まとめスレッド | 週1(土曜) | 今週の案件5選🧵 |

### 決算・IR翻訳型のテンプレ
```
【決算翻訳】◯◯(証券コード)、◯◯を発表。

数字: (売上/利益/買収額など事実を3行)

これを翻訳すると:
「(この会社が何を考えているかを一言で)」

根拠は3つ。
・(数字の根拠1)
・(根拠2)
・(根拠3)

だから次に起きるのは◯◯(予想は断定しない)。
```
ネタ元: TDnet適時開示、各社IRページ、EDINET。M&A・買収・TOB関連の開示を優先。

## 6. KPI(プロのマーケター視点での提言)

- X: インプレッション・ブックマーク(フォロワー数は追わない — 本家が証明済み)
- Instagram: **保存率(保存÷リーチ)3%超**を目標。次にプロフィールアクセス
- 週次で「保存が多かった案件タイプ」を見て翌週の選定に反映
- 90日継続を前提に設計(伸びるアカウントは例外なくストック型を90日続けている)

## 7. 立ち上げ手順

1. IGアカウント開設(ユーザー名はXと同じ)
2. こちらでカルーセルHTMLテンプレを実装 → サンプル7枚を納品 → デザインFIX
3. 以降、案件巡回のたびに「X原稿+IG7枚PNG」をセット納品
4. 初週はIG毎日1投稿(過去のX原稿16本からストック変換も可)
