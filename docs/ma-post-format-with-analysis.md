# 考察付き案件紹介フォーマット(M&A情報局のメイン投稿型)

単に案件を転載するのではなく、**「この数字をどう読むか」「誰がどう買うと勝てるか」まで踏み込む**のがこのアカウントの差別化ポイント。
評論ではなく、買い手・売り手が明日動ける実務目線で書く。

---

## 基本構造(1投稿 = 5パーツ)

```
① 案件の一言サマリ(地域|業種|価格)
② 数字(売上・利益・価格・従業員など3〜5個)
③ 考察(ここが本体。下の「考察の型」から1つ)
④ 誰向けか(この案件が刺さる人を1行で名指し)
⑤ 出典リンク
```

## 考察の型(ローテーションで使う7パターン)

| 型 | 中身 | 例文の書き出し |
|---|---|---|
| A. 回収年数 | 価格÷営業利益で何年で元が取れるか | 「利益○○万円に対して価格○○万円。単純計算○年で回収」 |
| B. 価格の理由 | なぜこの価格なのか(純資産+営業権/急ぎ売却/設備価値) | 「相場より安く見えるのは○○が理由と推測」 |
| C. 属人性リスク | 社長が抜けた後も売上が残るか | 「この業種の肝は常連客が“店”に付いてるか“人”に付いてるか」 |
| D. シナジー目線 | どんな既存事業と組むと化けるか | 「単体では小粒。ただ○○業の会社が買うと配送網が重なって化ける」 |
| E. 隠れ資産 | 許認可・立地・顧客リスト・SNSなど値段に出ない価値 | 「注目は価格より○○の許認可。新規取得だと○年かかる」 |
| F. 注意点 | DDで必ず見るべき箇所 | 「気になるのは○○。買付前に必ず確認したいのは…」 |
| G. 市場背景 | 業界トレンド・後継者問題と絡める | 「この業界、実は今売り案件が増えている。背景は…」 |

## 記入例(サンプル数字。実案件で置き換える)

### 例1: 型A+F(回収年数+注意点)
```
【本日の売り案件】📡
地方都市|コインランドリー2店舗

・売上: 1,200万円/年
・営業利益: 300万円
・希望価格: 900万円

単純計算で3年回収。無人経営で会社員の副業でも回る型。
ただしこの業態、機械の入替時期が利益を吹き飛ばす。設備の年式と修繕履歴はDDで最優先確認です。

副業で「箱もの」を持ちたい人向け。
出典: ○○(リンク)
```

### 例2: 型E(隠れ資産)
```
【気になる案件】📡
首都圏|廃業予定の運送会社

・売上: 8,000万円
・利益: ほぼトントン
・希望価格: 500万円

利益ゼロでなぜ500万?と思ったら、答えは「緑ナンバー(一般貨物の許認可)」。
新規取得は要件も時間も重い。同業や EC 物流に参入したい会社にとっては、許認可を買う案件です。

物流に足がかりが欲しい事業会社向け。
出典: ○○(リンク)
```

### 例3: 型C(属人性)
```
【本日の売り案件】📡
東北|老舗の和菓子店(創業60年)

・売上: 2,500万円
・利益: 400万円
・希望価格: 1,000万円
・譲渡理由: 後継者不在

数字は堅実。論点はひとつで、「この味とレシピは承継できるのか」。
職人が残ってくれる引き継ぎ条件なら優良案件、レシピが社長の頭の中だけならリスク案件。
面談で聞くべきは売上でなく製造体制です。

地方で「続く店」を継ぎたい人向け。
出典: ○○(リンク)
```

## 毎日の運用フロー(考察付き版)

1. バトンズ/TRANBI/スピードM&A/ラッコM&Aの新着を巡回(定点4サイト・15分)
2. 「考察が書ける案件」を選ぶ — 数字が公開されていて、型A〜Gのどれかに当てはまるもの
3. 5パーツ構造で下書き → 考察は必ず1つに絞る(2個以上書くと薄まる)
4. 断定しすぎない表現に調整(「〜と推測」「〜に見える」)— 案件の内情は外からは分からないため
5. 出典リンクを付けて投稿

## 自動化について(要・環境設定変更)

このドラフト作成は Claude 側で毎日自動化できる(毎朝、新着案件から考察付き下書きを数本作ってチャットに届ける)。
ただし現在この実行環境のネットワーク設定が X・各M&AプラットフォームへのアクセスをすべてブロックしているためNG。
環境のネットワークアクセス設定を変更(許可ドメイン追加 or 制限緩和)すれば稼働可能。
