# M&A情報局 デザイントンマナ+画像生成プロンプト集(Manus/ChatGPT用)

参考: https://areteco.com/ (ARETECO HOLDINGS)の実サイトを解析して抽出した方向性。

## トンマナ定義(v2: ARETECOインスパイア)

| 要素 | 指定 |
|---|---|
| ベース | 白(#FFFFFF)〜わずかにウォームな白。余白を贅沢に使う |
| メイン | 黒(#1A1A1A)の極太ゴシック。タイトルは画面幅いっぱいの大きさ |
| アクセント | **蛍光イエロー(#FFE93C)の手描き風マーカー**。キー数字・キーワードにだけ引く |
| サブアクセント | 赤(#E8442E)を「価格」「注目」など1画面1箇所まで |
| 雰囲気 | 雑誌の特集ページ/編集デザイン。ポップだが子供っぽくない。「面白いプロ」 |
| 文字 | 生成AIは日本語の文字を崩しやすい→**画像内の文字は最小限**にし、数字と短い単語だけ入れる。長文はキャプション側へ |
| 禁止 | 写真素材、グラデーション多用、ビジネス系フリーイラスト(手描き線画はOK) |

## 1. プロフィール画像(X・Instagram共通)

ChatGPT(イメージ生成)/Manusにそのまま貼るプロンプト:

```
正方形のSNSプロフィールアイコンをデザインしてください。

内容: 白背景に、黒の極太ゴシック体で「M&A」と大きく中央に配置。
「M&A」の文字の下半分に、蛍光イエロー(#FFE93C)の手描き風マーカーライン(蛍光ペンで勢いよく引いたような、端がかすれたストローク)を重ねる。
右上に小さく赤(#E8442E)の丸を1つ(電波・情報局のシグナル感)。

スタイル: 日本の雑誌の編集デザイン風。ミニマル。要素は3つだけ(文字/マーカー/赤丸)。
影・グラデーション・立体感・写真は使わない。フラットデザイン。
小さく表示されても判読できるシンプルさを最優先。
```

バリエーション(2案目): 「M&A」の代わりに「📡を図案化した黒线画+黄色マーカー」版。
```
白背景に、黒の太い線で描いたシンプルなパラボラアンテナ(電波を受信する情報局のイメージ)のアイコン。線は手描き風の勢いのあるストローク。アンテナが受信する電波を蛍光イエロー(#FFE93C)の短い斜線3本で表現。日本の雑誌デザイン風、ミニマル、フラット。正方形。
```

## 4. IGカルーセル7枚(毎日の案件投稿用)— マスタープロンプト

Manus/ChatGPTに「スタイル指示(固定)+その日の案件データ(可変)」を渡す構成。
**7枚を一気に生成させる場合**は以下を1回で貼る:

```
Instagramのカルーセル投稿用に、縦長(1080×1350)の画像を7枚、同一デザインシステムで作ってください。

【デザインシステム(全枚共通)】
- 白背景、余白たっぷり、日本の雑誌の編集デザイン風
- 見出しは黒の極太ゴシック体。キー数字は画面の1/3を占める大きさ
- キー数字・キーワードにだけ蛍光イエロー(#FFE93C)の手描き風マーカーラインを重ねる
- 「価格」に関する数字のみ赤(#E8442E)
- 各枚の上部に小さく「M&A情報局|案件シート」、下部に「n/7」のページ番号
- 写真・グラデーション・立体感なし。図形はフラットな線画のみ
- 画像内の文字は下記に指定したものだけを正確に描画(創作しない)

【各枚の内容】※以下は案件データで毎回差し替え
1枚目(表紙): 「(フック上段)」「(フック下段=価格)」+ 下部に小さく「スワイプで詳細→」
2枚目(概要): 業種「◯◯」/地域「◯◯」/従業員「◯◯」/業歴「◯◯」を2×2グリッドで
3枚目(数字): 売上「◯◯」・営業利益「◯◯」・希望価格「◯◯」を横棒の長さで比較する図
4枚目(回収): 「◯年で回収」を大きく+計算式「価格◯◯÷利益◯◯」を小さく
5枚目(考察): 見出し「この案件の読み方」+箇条書き3点(各15文字以内)
6枚目(注意): 見出し「買う前に確認する3つ」+箇条書き3点(各15文字以内)
7枚目(CTA): 「保存して比較検討」「フォローで毎日届く」+アイコン
```

### 運用メモ
- その日のX原稿から【各枚の内容】の◯◯を私(Claude)が埋めた「完成プロンプト」を毎回納品する → あなたはManus/ChatGPTに貼るだけ
- 生成後、日本語の文字化けがあった枚だけ「n枚目の『◯◯』の文字を修正して再生成」と追撃指示
- 品質が安定しないときの保険: 文字なし背景だけ生成→Canvaで文字載せ(テンプレ保存で2回目以降3分)
