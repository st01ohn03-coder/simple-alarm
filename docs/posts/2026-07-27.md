```
・売上: 3,000万〜5,000万円

この手の案件は、家賃・人件費・原価率をDDで必ず確認。数字次第で掘り出し物にも地雷にもなります。

飲食の2店舗目を安く構えたい経営者向け。
出典: https://speed-ma.com/projects/49990
```

## ⑤ 売上2,000万の銭湯が9,500万円(型E: 隠れ資産・逆パターン)

```
【気になる案件】📡
鹿児島|温泉銭湯

・売上: 2,000万〜3,000万円
・希望価格: 9,500万円

さっきと逆で、売上の3〜4倍の価格が付いている案件。
この価格はおそらく事業ではなく「不動産と温泉源」の値段。温泉権は新規で掘ると1億超も珍しくない。
買い手は銭湯経営者ではなく、宿泊・観光開発を考える会社になるはず。

温泉付き物件を探す開発・観光業者向け。
出典: https://speed-ma.com/projects/49989
```

## ⑥ 締めの学びポスト(①〜⑤の後、夜に)

```
今日紹介した案件、価格だけ並べると:

・年商1,700万の配食 → 0円
・売上3,000万の飲食 → 198万円
・売上2,500万の銭湯 → 9,500万円

会社の値段は売上では決まらない。
「利益」と「引き継げる資産」と「売り手の事情」で決まる。

これがM&Aの面白いところです📡
```
