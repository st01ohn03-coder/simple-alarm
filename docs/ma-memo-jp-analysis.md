## 勝ちパターンの投稿フォーマット(実例から抽出)

実際の投稿例:
```
売上3億〜5億円の会社が
10万円で売りに出てる。

退去立ち会い代行＋原状回復工事。
業歴15年。
取引先は大手不動産管理会社。
建設業許可・古物商・産廃許可あり。

10万円。

【M&A売却案件ピックアップ】

東京・埼玉エリア。
賃貸物件の退去に関わる業務を
ワンストップで請け負う会社。(以下長文)
```

### 構造の分解

1. **冒頭2行 = 数字ギャップのフック**: 「売上◯億の会社が◯万円で売りに出てる。」大きい数字と小さい数字の落差で指を止めさせる。改行位置も計算されている(1行目に大きい数字、2行目に価格)
2. **スタッカート箇条書き**: 短文をポンポン置く(営業利益/従業員/借入/許認可/業歴/取引先)。「・」を使う場合と使わない場合あり
3. **価格をもう一度ドン**: 「10万円。」と1行で再提示(最強の数字を2回使う)
4. **【M&A売却案件ピックアップ】** の定型ラベル → シリーズ化・検索性
5. **後半に長文の詳細**(地域→事業内容→強み)。長文にすることで「さらに表示」クリック=エンゲージメントを稼ぎ、アルゴリズム評価を上げる
6. **絵文字・ハッシュタグ・URLを本文に入れない**。Xは外部リンク付き投稿のリーチを下げるため、リンクレスで書き切る

### もう1つの型: M&Aニュース茶化し解説型

```
【衝撃】時価総額42億の会社、32億の買収を決断してしまうｗｗｗ

AIAIグループ(6557)、児童発達支援のハビーを子会社化。
・自社の時価総額の77%相当の買い物
＜何を買ったのか＞(以下解説)
```
上場企業の適時開示を「ｗｗｗ」混じりのくだけたトーンでフックし、中身は真面目に解説。案件紹介の合間の変化球として機能。

## 当局(M&A情報局)が真似ること・変えること

### 真似る
- 冒頭の数字ギャップフック(2行構成・改行位置まで)
- 【M&A売却案件ピックアップ】のようなシリーズラベル → 当局は「【M&A情報局|本日の案件】」等
- 本文にURLを入れない(出典リンクは**リプ欄にぶら下げる**方式に変更 — 規約遵守とリーチを両立)
- 長文で「さらに表示」を発生させる
- 絵文字ほぼなし・ハッシュタグなしの硬めトーン
- ニュース解説の変化球(適時開示ネタ)

### 変える(差別化)
- 本家は仲介業の集客が目的 → 当局は当面キュレーション専業。中立の立場を強調できる
- 本家は自分の扱い案件も紹介 → 当局は複数プラットフォーム横断(バトンズ/TRANBI/スピードM&A/ラッコM&A)で網羅性を出す
- 考察パート(回収年数・属人性・隠れ資産など7型)は本家より一歩深く書く — ここが当局の付加価値

## 運用上の学び

- フォロワーが少なくても気にしない。表示数(インプレッション)とブックマークをKPIにする
- 毎日1〜2本の案件ピックアップ+週数回の変化球、を1年近く継続している(578ポスト/約4年半)。継続が前提
