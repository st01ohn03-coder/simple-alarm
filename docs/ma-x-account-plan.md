## 1. コンセプト

日本国内の M&A「売り案件」「買い案件」情報を、大手から超小型案件まで横断的にウォッチし、
**「見ているだけで面白い/自分にもできそうと思える M&A 案件キュレーションアカウント」** として運用する。

### ターゲット(想定フォロワー)

| 層 | 具体像 | 刺さるネタ |
|---|---|---|
| 個人・サラリーマン買い手 | 「会社を買って独立/副業したい」層。300万〜1,000万円のスモールM&A志向 | 小型で買いやすい案件、意外と安い案件、儲かっている小商売 |
| 中小企業経営者(売り手) | 後継者不在・イグジット検討中。後継者不在率は約52%(帝国データバンク2024) | 同業種の売却事例、価格相場感、売り方の知識 |
| 事業会社・投資家(大型) | 買収による事業拡大を狙う法人、サーチファンド、個人投資家 | 数億円規模の案件、業界再編ネタ、適時開示 |
| Web系副業層 | サイト・SNSアカウント・ECなどデジタル資産の売買に興味がある層 | ラッコM&A等の面白案件、フォロワー○万人アカウントの値段 |

## 3. 運用フロー(案件収集 → 投稿まで)

```
[毎日] 収集(15分) → 選定(10分) → 加工(15分) → 予約投稿
[週1] まとめ投稿・振り返り・KPI確認
```

### STEP 1: 収集(毎朝15分)

- 各プラットフォームの「新着案件」ページを巡回(バトンズ/TRANBI/スピードM&A/ラッコM&A を最低限の定点に)
- 各PFの新着メール通知・キーワードアラートに登録(無料会員登録で可)
- X「M&Aソース」リストをチェック
- 気になった案件は **ネタ帳スプレッドシート** に転記:
  `日付 / 出典URL / 業種 / 地域 / 売上・利益 / 希望価格 / ひとことポイント / 使用済みフラグ`

### STEP 2: 選定(1日2〜4件)

選定基準(どれかに刺されば採用):
1. **意外性** — 「え、この値段で買えるの?」「この商売そんなに儲かるの?」
2. **ターゲット適合** — 個人が手を出せる小型案件と、法人向け大型案件をバランスよく
3. **物語性** — 後継者不在、地方の老舗、珍しい業種など語れる背景がある
4. **時事性** — ニュース・制度改定に絡められる

### STEP 3: 加工(コンプライアンス込み)

1. **転載規約チェック**: 案件詳細の丸写しはPF規約違反になり得る。**公開されている概要を自分の言葉で要約し、出典リンクを付ける**のを原則にする
2. 投稿テンプレ(下記)に流し込む
3. 数字(売上・利益・価格)は必ず載せる — この数字が最大のフックになる

### STEP 4: 投稿(予約投稿を活用)

| 時間帯 | 内容 |
|---|---|
| 朝 7:00–8:00 | 通勤層向け: スモール案件紹介(個人買い手ネタ) |
| 昼 12:00 | 軽いネタ・雑学・相場クイズ系 |
| 夜 20:00–22:00 | メイン投稿: 注目案件の深掘り、大型案件、スレッド |
| 週末 | 「今週の面白案件まとめ」スレッド |

### STEP 5: 週次振り返り(KPI)

- フォロワー数 / インプレッション / プロフィールクリック / ブックマーク数
- ブックマークが多い投稿タイプ = 「あとで見返したい案件情報」なので、その型を増やす

## 4. 投稿テンプレート

### ① 案件紹介型(メイン・毎日)

```
【売り案件メモ】○○県|△△業

・売上: ○○万円
・利益: ○○万円
・希望価格: ○○万円
・従業員: ○名

(ひとこと所感: なぜ面白いか、誰に向いてるか)

出典: (PF名・リンク)
```

### ② 個人買い手向け「これ買える」型

```
サラリーマンの貯金でも狙える案件があった。

○○(業種)、希望価格○○万円。
利益○○万円だから○年で回収できる計算。

こういうのがゴロゴロ眠ってるのがスモールM&A。
```

### ③ 相場・雑学型(昼向け)

```
フォロワー8万人のXアカウント、いくらで売られてると思いますか?

答え: ○○万円(スピードM&Aに実案件あり)

デジタル資産のM&A、相場はだいたい…(続く)
```

### ④ 週末まとめスレッド型

```
今週見つけた面白M&A案件 5選🧵

① 後継者不在の老舗○○(○○万円)
② …
```

### ⑤ 売り手向け啓蒙型

```
中小企業の後継者不在率、52%。
黒字のまま廃業する会社が毎年たくさんある。

「売る」という選択肢を知ってるだけで結末が変わる。
```

## 5. 注意点(必読)

1. **転載・著作権**: 各PFの案件文面のコピペ転載は規約違反リスク。要約+出典リンクを徹底
2. **秘密保持**: NDA締結後に得た非公開情報は絶対に投稿しない。投稿するのは誰でも見られる公開案件情報のみ
3. **仲介行為との線引き**: 案件の「紹介・あっせん」を業として行い報酬を得る場合は、中小M&Aガイドライン・M&A支援機関登録制度の対象になり得る。当面は「情報キュレーション」に徹する
4. **SNSアカウント売買ネタ**: Xアカウント単体売買は規約違反リスクがあるため、「事業譲渡の一部としての承継」という正しい建付けで紹介する
