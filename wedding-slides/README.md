# 結婚式2次会スライド（骨組み）

`index.html` をブラウザで開くだけで動く、自己完結のスライドです。

## 操作

| 操作 | キー |
| --- | --- |
| 進む（クイズは1回目で正解表示、2回目で次へ） | → / Space / Enter / 画面右側クリック |
| 戻る | ← / 画面左側クリック |
| 最初 / 最後へ | Home / End |

URL の `#12` のように番号を付けると、そのスライドから始まります。

## 構成

### Opening
1. タイトル（新郎新婦の名前・日付を入れる）
2. 本日の流れ ①クイズ大会 ②中村になろうよ ③ビンゴ大会

### Part 1 クイズ大会（全7問）
3. 扉
4. ルール説明
5. Q1 初めてのデートで新郎がやらかした失敗は？ → A. 待ち合わせに遅刻（1時間）
6. Q2 新婦が新郎に「これだけはやめてほしい」と思っている癖は？ → A. 酔って帰ってきてダル絡み
7. Q3 喧嘩したとき新郎が必ずすることは？ → A. コンビニでアイスを買ってくる
8. Q4 新婦が思う「新郎の手料理で一番美味しいもの」は？ → A. 参鶏湯
9. Q5 幼少期の写真、新郎はどれ？（写真4枚を差し替え・正解位置を設定）
10. Q6 新郎は腕立て伏せを何回できる？（ニアピン方式・回数を確認）
11. Q7 入籍前にやらかしたエピソードは？ → A. 新郎が社員旅行で左手薬指を負傷
12. 結果発表

### Part 2 中村になろうよ
13. 扉
14. ルール説明（内容確定待ち）
15. Round 1 お題（ラウンド数に応じて複製）
16. 結果発表

### Part 3 ビンゴ大会
17. 扉
18. ルール説明
19. 景品一覧
20. 抽選ボード（1〜75 のランダム抽選つき。リセットは確認ダイアログあり）

### Ending
21. 新郎新婦よりご挨拶
22. Thank you

- ビンゴの景品リストと、選択制か順位制か
- 挨拶の順番と写真撮影の案内

## 差し替え方

- 正解の選択肢は `<li class="choice" data-correct>` の `data-correct` を付け替える
- 写真は `.photo` の中身を `<img>` に置き換える（`data-correct` を正解の写真に付ける）
- ラウンドを増やすときは Round 1 の `<section>` をコピーする
