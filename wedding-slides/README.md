# 結婚式2次会スライド

先輩の結婚式2次会（クイズ大会 → 中村になろうよ → ビンゴ大会）用のスライドです。
手作り感のあるスクラップブック風のデザインで、紙・マスキングテープ・付箋・ポラロイド・
赤ペンの丸つけで構成しています。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `結婚式2次会スライド.pptx` | 本命。PowerPoint で編集して本番に使う |
| `結婚式2次会スライド.pdf` | 保険。フォント埋め込み済みで、どのPCでも見た目が崩れない |
| `index.html` | ブラウザ版。ビンゴ抽選機つき |
| `fonts/` | スライドで使っている手書き風フォント |
| `build/` | pptx を作り直すためのスクリプトと素材 |

## 使う前に：フォントを入れる

pptx は次の3書体を使っています。入っていないと別の書体で表示され、手書き感が出ません。

- Yusei Magic（見出し）
- Zen Kurenaido（本文）
- Caveat（英字の飾り）

`fonts/` の3つの ttf をダブルクリックしてインストールしてください。
Windows なら右クリックから「すべてのユーザーに対してインストール」、Mac なら Font Book が開きます。
どれも Google Fonts の無料フォントです（SIL Open Font License、`fonts/OFL-*.txt` を同梱）。

フォントを入れられない環境で発表するときは、PDF を使ってください。
PDF はフォントが埋め込まれているので、そのままの見た目で表示されます。

## 本番までに埋めるところ

スライド上では水色のラベルで示しています。本番前に削除してください。

- 新郎新婦の名前と日付（1枚目）
- クイズ優勝者の決め方と景品、同点時の処理（4枚目・19枚目）
- Q5 の幼少期の写真4枚と、正解の位置（13-14枚目）
- Q6 の腕立て伏せの回数（16枚目）
- 「るい or るいぴー」の質問を入れるかどうか
- 中村になろうよ のルール、参加者の選び方、ラウンド数（21-22枚目）
- ビンゴの景品リスト、選択制か順位制か（25-26枚目）
- 挨拶の順番と写真撮影の案内（28枚目）

各スライドのノート欄に、進行のメモを入れてあります。発表者ツールで確認できます。

## 差し替え方

**写真（Q5）**
グレーの四角の上に写真をドラッグして重ね、右クリックから「最背面へ移動」ではなく、
グレーの四角を選んで削除してから写真を配置すると早いです。

**正解の位置を変える**
赤い丸は画像として置いてあります。正解の選択肢の上にドラッグで移動してください。
薄くなっている「はずれ」の付箋と、色がついている「正解」の付箋も入れ替えが必要です。

**ラウンドを増やす（中村になろうよ）**
22枚目を右クリックして「スライドの複製」を選びます。

## 作り直す

`build/` にスクリプトを入れてあります。素材から作り直す場合は次の通りです。

```bash
cd build
python3 make_assets.py     # 紙・テープ・赤丸などの素材を生成
npm install pptxgenjs
node build_deck.js         # pptx を出力
```
